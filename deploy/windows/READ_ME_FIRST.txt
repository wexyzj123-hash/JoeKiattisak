AIAT Safety + Hub  —  ชุดติดตั้งสำหรับ Windows
=================================================

เริ่มใช้งานใน 3 ขั้น
  1) แตกไฟล์ Zip ไว้ที่โฟลเดอร์ถาวร เช่น C:\AIAT-Safety   (อย่ารันจากในไฟล์ Zip)
  2) ดับเบิลคลิก  install.bat   (ต้องต่ออินเทอร์เน็ตครั้งแรกเพื่อโหลดไลบรารี)
  3) ดับเบิลคลิก  start.bat     แล้วเว็บจะเปิดที่ http://localhost:5000
     - ครั้งแรกที่หน้า /setup ให้สร้างผู้ดูแลระบบคนแรก
     - กดไทล์ "ความปลอดภัย (Safety)" เข้าระบบได้ทันที

ไฟล์ในชุดนี้
  install.bat    ติดตั้ง Python venv + ไลบรารี + สร้าง .env (ความลับสุ่ม) + ตรวจระบบ
  start.bat      เปิด Hub (5000) และ Safety (5200)
  stop.bat       ปิดระบบ
  backup.bat     สำรองฐานข้อมูลและรูปภาพไว้ที่โฟลเดอร์ backup\  (คัดลอกออกจากเครื่องเป็นประจำ)
  autostart.bat  (Run as administrator) เปิดระบบเองเมื่อเปิดเครื่อง + เปิดไฟร์วอลล์ 5000/5200
  .env           ค่าตั้งค่าและความลับ (สร้างตอนติดตั้ง) — ห้ามแจกจ่าย
  docs\DEPLOY.md รายการตรวจสอบหลังติดตั้ง (ให้สิทธิ์ → ข้อมูลหลัก → ทดลองแจ้งเตือน → ทดลองกลุ่มเล็ก)

ใช้จากเครื่องอื่นในบริษัท
  ตอน install.bat ให้พิมพ์ชื่อเครื่องหรือ IP ของเซิร์ฟเวอร์ (เช่น 192.168.1.10) แล้วรัน autostart.bat เพื่อเปิดไฟร์วอลล์
  ถ้าติดตั้งไปแล้วและต้องการเปลี่ยน: แก้ HUB_URL / SAFETY_URL ใน .env แล้วแก้ที่อยู่ระบบที่ Hub > ทะเบียนระบบ

อัปเกรดเวอร์ชัน
  stop.bat > backup.bat > แตกไฟล์ใหม่ทับ (ไม่ทับ .env, hub\data, safety\data) > install.bat > start.bat
  ฐานข้อมูลอัปเกรดตัวเองตอนเปิดระบบ

หมายเหตุ
  - แจ้งเตือน Telegram/LINE/Teams/อีเมล: ใส่ค่าใน .env (ดูตัวอย่างที่ถูกคอมเมนต์ไว้) แล้ว stop.bat > start.bat
  - ถ้าต้องการฟอนต์ Sarabun ใน PDF วาง Sarabun-Regular.ttf และ Sarabun-Bold.ttf ที่ shared\assets\fonts\
  - ใช้งานจริงควรวาง reverse proxy ที่มี https หน้าระบบ (ดู docs\DEPLOY.md)
